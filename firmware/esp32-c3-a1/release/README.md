# ESP32-C3 A1 修复固件 · 2026-10-24

修复 A1 四色屏刷新后中间出现竖向明暗带的问题。已在原 C3 3V3/GND 接线下，强制刷新同一张照片并由用户确认“仍然正常，没有中线”。

这是现有 InkSight 安装的 **app0 升级包**。适用 ESP32-C3、A1、768×552 四色屏及本文指定的已有固件/分区；不是新板的全片初始化包。

## 使用顺序

1. 阅读 [接线说明](WIRING.md)，本版 **RST = GPIO2**。
2. 按 [刷写方法](FLASHING.md) 备份设备，再运行离线适配检查。
3. 检查通过后只把 `.app.bin` 写到 **0x10000**，完成核验再启动。
4. 保留原 Wi-Fi 和服务配置，通过局域网服务端“立即刷新”检查照片。

## 修复与验证

完整 A1 初始化与扫描窗口；单次 0x10 连续 CS 传完 105,984 字节；刷新及关屏均等待 BUSY 完整结束。保留原 RAW 线序、GPIO、8.5 dBm、Wi-Fi 配置和已有局域网服务连接方式。

固件 SHA-256：`befb5bd8e02547f2ab21f36272e75e9b613e1a6f1c60130c6756bf1529023c10`，1,202,896 字节。适配代码的 13 项构建测试、16 个 RV32 场景及 A0 分派验证通过。原接线同照片刷新约 18.7 秒；没有 A0 实屏验收，不将本次效果扩展为所有批次保证。

服务端配套的“相同照片立即刷新”修复见 [PR #1](https://github.com/3dhaoxinren/miaomo-server/pull/1)。相框数量等服务端界面功能不由本应用升级包改变。

仅在可信局域网中使用免登录的喵墨服务端。本包不包含个人照片、Wi-Fi 密码、设备配置、文件系统或 flash 备份。
